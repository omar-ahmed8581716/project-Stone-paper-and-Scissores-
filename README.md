# 🎮 Rock, Paper, Scissors - C++ Game

A simple C++ console game played against the computer, built with clean and modular code.

## 🛠️ Highlights
- **Clean Architecture:** Uses functions, `structs`, and `enums` for organized code.
- **Input Validation:** Prevents invalid user inputs.
- **Dynamic UI:** Changes terminal screen colors based on win/loss/draw results.

## 🚀 How to Run
Open `main.cpp` or `ProjectRockPaperScissores.cbp` in **Code::Blocks**, then Build & Run (`F9`).
